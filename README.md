# Basic Chatbot

Writing a chatbot from scratch to learn how to build one and get back to writing code. I'm focusing local models only so I can do this without an internet connection but a cloud fallback can be implemented at some point.

## Tech Stack
- Node v24.11.1
- Express
- Ollama
- MiniCPM-2B
- Bruno

## Running the Project
### Install Dependencies
- Install Ollama
- Install MiniCPM - [link](https://github.com/OpenBMB/MiniCPM/blob/main/docs/deployment/ollama.md)
- Clone project and run `npm i`
